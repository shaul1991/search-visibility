# Gemini 웹 앱의 공개 출처 링크 관측

[English guide](gemini-app.en.md)

1. 사용 언어와 국가의 지원 여부를 확인하고 웹에서 새 채팅을 시작합니다. 반복 관측에서는 질문, 모델, 계정 유형이나 로그인 상태, 기기, 연결한 앱을 같은 조건으로 유지합니다. 실제 관측 국가는 질문 로캘과 별도로 기록하고, 관측 시각은 UTC 오프셋과 함께 남깁니다. 모바일 앱의 지원 범위는 다를 수 있습니다. [Gemini 웹 앱 지원 범위](https://support.google.com/gemini/answer/13575153?hl=ko)
2. 질문과 응답 본문을 그대로 저장합니다. 원래 응답의 **출처** 패널과 본문 링크를 확인합니다. 출처나 관련 콘텐츠로 표시된 공개 웹 페이지의 최종 URL을 `sources`에 넣습니다. 비공개 Workspace 문서와 업로드 파일은 제외합니다. 응답을 관측했지만 해당 링크가 없으면 `sources: []`를 사용합니다. 차단되거나 응답을 얻지 못한 시도는 별도 로그에 기록합니다. [Gemini 출처 확인](https://support.google.com/gemini/answer/14143489?hl=ko)
3. `engine: "gemini-web"`을 사용하고 질문 언어와 관측 국가별로 소유 URL이 하나 이상 표시된 응답 수와 전체 관측 응답 수를 함께 보고합니다. 이 지표는 관련 콘텐츠를 포함해 화면에 표시된 링크를 집계합니다. Google 검색 AI 모드, Gemini API 그라운딩 등 다른 서비스에는 별도 엔진 이름을 부여합니다. 반복 측정에는 [같은 조건으로 전후를 비교하는 절차](ai-comparison.ko.md)를 적용합니다.

저장소 루트에서 아래 합성 예제를 실행합니다. [개별 설치한 스킬의 CLI](../README.md#개별-설치한-스킬에서-cli-실행)에서도 같은 설정 파일을 사용할 수 있습니다.

```sh
npm run visibility -- examples/gemini-app/config.json --out ./gemini-app-sample
```

관측 응답 2건 중 1건에서 소유 링크가 집계됩니다. 한국어 질문에는 국제화된 공유 호스트의 소유 계정 링크가 표시됩니다. 호주 영어 질문에는 같은 호스트에서 이름이 비슷한 다른 계정 링크가 표시됩니다. 두 관측의 현지 날짜는 다르며 UTC 기준 시각은 같습니다.
