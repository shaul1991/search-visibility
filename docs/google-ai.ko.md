# Google AI 개요·AI 모드 가시성 측정

[English guide](google-ai.en.md)

Search Console에서 속성을 선택한 뒤 **생성형 AI 실적 보고서(검색)**를 엽니다. Google은 2026년 8월 31일 기준 전 세계 출시를 공지했습니다. 보고서가 보이지 않으면 노출수가 충분한지, 속성의 검색 생성형 AI 설정에서 포함을 허용하는지 확인합니다. [Google 출시 공지](https://developers.google.com/search/blog/2026/06/gen-ai-performance-reports) · [보고서 도움말](https://support.google.com/webmasters/answer/16984139?hl=ko)

| 근거 | 기록할 내용 |
| --- | --- |
| Search Console 생성형 AI 실적(검색) | AI 개요와 AI 모드의 노출수입니다. 속성, 기간, 검색 유형(텍스트 기반 또는 멀티모달), 페이지·국가·기기 필터를 기록합니다. Search Labs 실험은 집계에서 제외됩니다. 선택 범위의 합계는 차트에서 확인합니다. 페이지별 표의 합계는 집계 단위가 달라 속성 전체 합계와 다를 수 있습니다. |
| Search Console 검색 결과 실적의 웹 유형 | 웹 검색 합계에 AI 기능에서 발생한 데이터가 이미 포함됩니다. 클릭수와 노출수가 있는 표는 기존 CSV 가져오기를 사용합니다. 웹 합계에 AI 노출수를 더하면 중복 집계됩니다. |
| Search Visibility 로컬 보고서 | 제품 화면별로 수집한 답변 수와 소유 URL을 인용한 답변 수를 기록합니다. 노출수만 담긴 생성형 AI 내보내기 파일은 측정 기록에 보관합니다. 현재 CSV 가져오기에는 클릭수와 노출수가 모두 필요합니다. |

Search Console 날짜는 태평양 시간(PT) 기준입니다. 내보내기를 비교할 때 같은 필터를 적용하고, 수집이 완료된 기간을 PT로 기록합니다. 보고서의 국가는 검색이 발생한 국가입니다. 로컬 관측의 `locale`은 질문에 사용한 언어와 로캘입니다. 실제 검색 지역, 기기, 로그인 상태는 따로 기록합니다. AI 답변이 표시되지 않은 시도는 수집 기록에 남깁니다. 답변이 표시됐지만 출처 링크가 없으면 `sources: []`를 사용합니다. [변경 전후 비교](ai-comparison.ko.md)

저장소 루트에서 합성 예제를 실행합니다.

```sh
npm run visibility -- examples/google-ai/config.json --out ./google-ai-sample
```

답변 두 건 중 한 건에서 소유 출처를 인용합니다. 한국어 AI 개요는 `bücher.example`의 퓨니코드 주소를 인용하고, 캐나다 프랑스어 AI 모드 답변은 다른 도메인을 인용합니다. 두 관측은 서울 11월 14일 00:30과 태평양 시간 11월 13일 07:30으로 같은 시각입니다. 이 시각을 Search Console 날짜에 맞출 때는 11월 13일을 사용합니다. 화면별로 합성 답변이 한 건씩이므로 입력과 출력 형식 확인에 사용합니다. [개별 설치 스킬](../README.md#개별-설치한-스킬에서-cli-실행)에서도 같은 설정 파일을 실행할 수 있습니다.
