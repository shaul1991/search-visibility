# AI 답변의 언급과 인용 관측

관측 단위는 한 엔진이 한 질문에 반환한 답변 한 건입니다. 사용자에게 브랜드 정식 명칭·별칭, 소유 도메인과 관측할 질문을 확인합니다. 질문에 브랜드명을 넣은 표본과 일반적인 추천 질문 표본은 따로 비교합니다.

1. 사용자가 제공한 답변 원문과 그 답변에 실제로 표시된 출처를 준비합니다. 직접 관찰할 때는 같은 질문 문구를 사용하고 엔진, 관측 일시, 가능한 경우 모델과 언어를 기록합니다. 답변을 확보하지 못한 질문은 미관측으로 표시합니다.
2. 답변 본문에 브랜드나 지정 별칭이 나타나는지 확인합니다. 동명이인, 일반 단어와 겹치는 이름, URL 경로에만 등장한 이름을 검토합니다. 공식 자료가 인용됐는지는 출처 URL의 호스트와 소유 도메인을 비교합니다. 하위 도메인도 포함합니다.
3. 엔진별·전체 표본 수와 함께 언급률·인용률을 기록합니다. 언급률의 분자는 브랜드를 언급한 답변 수, 인용률의 분자는 소유 도메인을 하나 이상 인용한 답변 수입니다. 분모는 실제로 확인한 답변 수입니다. 동일 답변의 여러 인용은 한 건으로 셉니다.
4. 재점검할 때는 같은 질문·언어·엔진 조합의 결과를 비교하고 관측 기간과 표본 수를 함께 제공합니다. 예시 데이터로 얻은 수치는 예시라고 표시합니다.

## 로컬 집계

배포된 `seo-orchestrator`의 통합 CLI에서도 이 기록을 집계할 수 있습니다. 각 관측의 `engine`, `query`, `observedAt`, `answer`, `sources`를 채웁니다. `observedAt`은 날짜 또는 시간대가 포함된 ISO 일시입니다. `answer`에는 출처 목록을 분리한 본문을 넣습니다. `sources`에는 답변이 직접 제시한 HTTP(S) 출처 URL을 넣고, 확인한 답변에 출처가 없으면 빈 배열을 넣습니다. `evidenceUrl`에는 선택적으로 답변을 다시 볼 수 있는 URL을 기록합니다. 공유할 결과에 포함해도 되는 주소를 사용하세요.

본문 판정은 대소문자와 전각·반각을 정규화한 문자열 일치입니다. 한글 조사 일부를 처리하며 띄어쓰기 변형·다른 언어 이름은 별칭에 명시합니다. 엔진의 문맥과 동일 이름을 쓰는 다른 브랜드는 결과의 일치 표현으로 확인합니다. 관측이 없거나 추적할 도메인을 지정하지 않았으면 해당 비율은 미측정으로 표시합니다.
